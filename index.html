🎹 Instrument plug-ins

Add instrument sounds from SoundFont (.sf2) files, which you can download for free online (search for “free sf2 soundfont”, e.g. on musical-artifacts.com). Each instrument in the file appears in the parts’ Instrument menu.

VST and AU plug-ins only work inside desktop music programs, not in a web page, but many of them also come in an .sf2 version.
